# TOTP генераторы мен тексерушісі (Java 17)

## Іске қосу
1. VS Code-та осы буманы ашыңыз.
2. JDK 17+ және Maven орнатылғанын тексеріңіз.
3. Терминалды ашып, жоба бумасында орындаңыз:
   - `mvn test`
   - `mvn compile`
4. VS Code-та `src/main/java/kz/project/totp/Main.java` файлын ашып, Run батырмасын басыңыз.

## Мәзір
1 — пайдаланушы қосу  
2 — пайдаланушыларды көру  
3 — TOTP кодын генерациялау  
4 — кодты тексеру  
5 — қалған уақытты көру  
0 — шығу

Деректер `data/users.csv` файлына сақталады.

## ООП қағидалары
- Инкапсуляция: `User` класының өрістері private.
- Абстракция: `AbstractAuthenticator` абстракт класы және `CodeGenerator` интерфейсі.
- Мұрагерлік: `TotpAuthenticator extends AbstractAuthenticator`.
- Полиморфизм: `UserRepository` интерфейсіне `CsvUserRepository` объектісін беру.

## Коллекциялар
- `ArrayList` — пайдаланушылар тізімі және CSV жолдары.
- `HashMap` — пайдаланушыларды ID бойынша сақтау.

## Ескерту
Бұл оқу жобасы. CSV ішіндегі TOTP құпия кілттері ашық мәтінмен сақталады. Нақты өндірістік жүйеде құпия кілттерді шифрлап сақтау, қолжетімділікті шектеу және резервтік көшіру қажет.
